# 🛡️ DNF 小团体优化助手 (DNF Optimize)

🎭 **让复盘变得更专业！** 当群聊中有人 @某位群友 并且消息里带有触发词（如“优化”、“伤害低”）时，机器人会代表小团体发送一段极其专业的“辞退通知”。

## ✨ 触发词示例
默认关键词：`优化`、`伤害低`、`奶太小`、`奶小`、`没伤害`、`输出低`、`太菜`、`垃圾数据`。

## 🚀 安装方法

1. 在 AstrBot 仪表盘 -> **插件管理**。
2. 点击 **通过 GitHub URL 安装**。
3. 输入本仓库链接：`https://github.com/yunko1993/astrbot_plugin_dnf_optimize`
4. 安装完成后，无需重启，插件会自动在 `data/plugin_data/` 创建配置。

## 📖 管理指令

| 指令 | 说明 | 权限 |
| :--- | :--- | :--- |
| `/opt_list` | 查看当前所有触发词 | 所有人 |
| `/opt_add [词]` | 新增触发词 | 仅管理员 |
| `/opt_del [词]` | 删除触发词 | 仅管理员 |

## ⚙️ 配置文件
第一次运行后，可以在 `data/plugin_data/astrbot_plugin_dnf_optimize/config.json` 中手动修改管理员 QQ 号 (`admin_qq`)。
